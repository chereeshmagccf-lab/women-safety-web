# 🛡️ Women Safety Web Application

A web-based **Women Safety and Emergency Assistance System** developed using **Python and Flask**. The application provides features such as emergency assistance, SOS alerts, location-based services, safety alerts, analytics, and machine-learning-based risk assessment.

## 🚀 Features

* 🔐 User registration and authentication
* 🚨 Emergency/SOS assistance
* ⚠️ Safety alert management
* 📍 Location-based safety services
* 🗺️ Map-based dashboard
* 📊 Safety analytics dashboard
* 🤖 Machine-learning-based risk assessment
* 🗄️ Database management using SQLite
* 👤 User and emergency information management

## 🛠️ Technologies Used

* Python
* Flask
* HTML5
* CSS3
* JavaScript
* SQLite
* Machine Learning

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/your-username/women-safety-web.git
cd women-safety-web
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```

Open the application in your browser using the local Flask server address.

## 🎯 Objective

The goal of this project is to create a centralized web platform that helps users access safety-related features quickly by combining **emergency assistance, alerts, location services, analytics, and intelligent risk assessment**.
